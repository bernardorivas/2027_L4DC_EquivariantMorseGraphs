# An Equivariant Approach to Topological Dynamics

Code and Lean 4 formalization for the paper by Bernardo Rivas and Kaito Iwasaki (in preparation).

- `code/`: the Python package `latent_equivariance`; see `code/README.md`.
- [Examples](code/examples/README.md): reproduce the figures and quotient computations, and prepare data for equivariant learning.
- `lean/`: the Lean 4 formalization; see `lean/README.md`.
