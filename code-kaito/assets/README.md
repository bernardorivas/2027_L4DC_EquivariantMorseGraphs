# Analytical sphere field

`sphere-field.png` is the normalized tangent-field panel used in the manuscript.
The arrows evaluate the stated sphere ODE and show direction, not speed.
The notebook combines this panel with a newly evaluated time-three height map.

The editable source is `../matlab/sphere_field_matlab.m`. In MATLAB, run
`sphere_field_matlab(true)` from that folder. The image is exported to
`artifacts/sphere-matlab-paper/sphere-field.png`. Notebook execution uses the
included PNG and requires no MATLAB installation.
