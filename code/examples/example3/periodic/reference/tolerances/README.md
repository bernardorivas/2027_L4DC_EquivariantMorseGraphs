# Example 3 attracting-region reference

The selected nominal and coning checkpoints are their respective `reference/nominal/seed0/model` and `reference/coning/seed0/model` directories. At 128 cells and time one, the nominal region contains 127 cells and has numerical tolerance `0.294831173680`, against maximum sampled residual `0.0148709675332`. The coning aggregate region contains 126 cells and has tolerance `0.172167905429`, against residual `0.0148921780616`. These comparisons use the chordal metric on the latent sphere, after undoing the learned monotone interval coordinate. Both pass.

From `code/`:

```bash
python examples/example3/run.py periodic tolerances --policy nominal --model examples/example3/periodic/reference/nominal/seed0/model --out outputs/example3-nominal-tolerances
python examples/example3/run.py periodic tolerances --policy coning --model examples/example3/periodic/reference/coning/seed0/model --out outputs/example3-coning-tolerances
```

Each command generates the 4,096 held-out trajectories with seed `2026111323`, uses all 23 one-second windows per trajectory, and generates 4,096 new one-second trajectories with seed `2026111341`. This is 98,304 physical observation pairs per policy. The learned time-0.1 map is iterated ten times. Each interval image uses 257 samples with padding `2e-6`. Generated trajectories start on `eta=0`, with independent translation and heading.

To reuse the held-out observations generated by an earlier replay, add `--data outputs/example3-replay/data`. A single matching `nominal-test.npz` or `coning-test.npz` file is also accepted. Fresh one-second trajectories are still generated. The optional dataset must contain finite `observations` at spacing 0.1 and the `times` array. The caller determines the physical scope of supplied observations.

For another checkpoint, replace `--model` with its directory containing matching `config.json`, `weights.npz`, and `normalization.npz`. A smaller `--samples` value changes the trajectory count for a trial run. The coning aggregate is recomputed from the new graph, including connecting cells and its native Conley index. If its structural checks fail, the raw graph and the reason remain in the output.

All six retained models pass the sampled comparison. [summary.json](summary.json) contains their hashes and both metrics. In the direct scalar coordinate, the selected nominal tolerance/residual pair is `(0.0942796734314, 0.0135148167610)` and the coning pair is `(0.0447725323181, 0.00918981432915)`. Do not compare one metric's tolerance with the other metric's residual.

The original warm native CMGDB medians were 0.38 ms for nominal control and 0.43 ms for coning, using precomputed image hulls. Image construction took about 12 ms per policy and residual evaluation took 0.214 s. Region extraction includes structural aggregation and native recomputation of its indices. Model loading, compilation, physical sample generation, plotting, and sphere-index reconstruction are separate.

These are numerical comparisons on sampled observations of the invariant subsystem. They are not uniform physical certificates. [The shared method](../../../../common/attracting_regions.md) describes the computation and adapter interface. The separate [manifest](manifest.json) protects the reference summary.
